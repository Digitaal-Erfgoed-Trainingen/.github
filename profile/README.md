## Welkom bij de Digitaal Erfgoed trainingen

Op deze plek is een verzameling digitaal cursus materiaal gepubliceerd voor iedereen die met digitaal erfgoed aan de slag wilt. De cursussen zijn ontwikkeld voor zowel erfgoed vrijwilligers als erfgoed professionals. 


### Module 1 - Dataorganisatie in spreadsheets voor bouwhistorie 
De module Dataorganisatie in spreadsheets voor bouwhistorie is ontwikkeld voor erfgoedvrijwilligers en professionals die systematisch gegevens verzamelen over bouwhistorische objecten. Goede dataorganisatie vormt de basis van elk project. Een spreadsheet (bv. een Excel-bestand) is een goede manier om data in op te slaan. Meestal beginnen we data te organiseren op een manier die voor ons als mensen prettig is om mee te werken. Computers vereisen echter dat data op een specifieke manier wordt georganiseerd. Om data te koppelen en om tools te kunnen gebruiken die analyses en zoeken efficiënter maken, zoals programmeertalen (bijvoorbeeld R of Python), of een database, moeten we onze data structureren op een manier die computers kunnen verwerken.

[Repository](https://github.com/Digitaal-Erfgoed-Trainingen/Dataorganisatie_spreadsheets_bouwhistorie)

[Gepubliceerde module](https://digitaal-erfgoed-trainingen.github.io/Dataorganisatie_spreadsheets_bouwhistorie/)


### Module 2 - Relationele Databases voor bouwhistorie
De module Relationele Databases voor bouwhistorie is een vervolg op Module 1, maar kan - bij voldoende voorkennis - ook autonoom worden gevolgd. In deze module staat het idee van een Relationele database centraal. Het doel van deze module is de deelnemers een begrip krijgen wat relationele databases inhouden en wat hiervan de voor en nadelen zijn. Ook geeft de module richting welke software er is en welke vervolgstappen zij/hij zou kunnen zetten. De module leert niet om een relationele database daadwerkelijke te ontwikkelen. 

[Repository](https://github.com/Digitaal-Erfgoed-Trainingen/Relationele_database_bouwhistorie)

[Gepubliceerde module](https://digitaal-erfgoed-trainingen.github.io/Relationele_database_bouwhistorie)

### Module 3 - Datakwaliteits richtlijnen Rijksdienst voor het Cultureel Erfgoed
#### Module 3.1 - Datakwaliteit van niet Ruimtelijke data
De module Datakwaliteitsrichtlijnen bouwt voort op module 1, maar geeft een inzicht hoe deze principes relateren aan de datakwaliteitsrichtlijnen van de [Rijksdienst voor het Cultureel Erfgoed](https://www.cultureelerfgoed.nl/). Wanneer bij het opzetten en verwerken van de data de richtlijnen worden gevolgd wordt het makkelijker datasets te adopteren en te koppelen met datasets van de dienst.
